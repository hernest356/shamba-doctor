# 🌱 Shamba Doctor

**Shamba Doctor** is an AI-powered farming assistant designed to help farmers get solutions to common agricultural problems.

## About the Project
Shamba Doctor is a chatbot that provides farming advice, helps identify crop and livestock diseases, and offers possible solutions to farm-related challenges.

## Features
- AI-powered farming chatbot.
- Crop disease identification and advice.
- Livestock disease information.
- General farming assistance.
- Interactive chat interface.

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- OpenAI API

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hernest356/shamba-doctor.git
   ```

2. Navigate to the project folder:
   ```bash
   cd shamba-doctor
   ```

3. Install dependencies:
   ```bash
   pip install flask mysql-connector-python openai
   ```

4. Configure your database and OpenAI API key using environment variables.

5. Run the application:
   ```bash
   python app.py
   ```
